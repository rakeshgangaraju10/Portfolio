## Run locally

```bash
git clone https://github.com/rakeshgangaraju10/Portfolio.git
cd Portfolio
```

Then open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
# visit http://localhost:8000
```

## Deploy with GitHub Pages

1. Push the files to the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. The site is published at `https://rakeshgangaraju10.github.io/Portfolio/` within a minute or two.

## Updating the content

All content lives in `index.html`, organised in clearly commented sections (`HERO`, `EXPERIENCE`, `PROJECTS`, `EDUCATION`, `TECHNICAL SKILLS`, `CERTIFICATIONS`, `ADDITIONAL INFORMATION`). To update the resume download, replace `Rakesh_G.pdf` with a new file of the same name.
