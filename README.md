## 📂 Projects Included

### 🧾 CareerForge – AI Resume-to-Job Matching Platform (Live)
- Full-stack analytics web app that scores resume-to-job fit with explainable 0–100 match scores, matched skills, gaps, evidence, and downloadable reports.
- React + TypeScript frontend and Django REST Framework API on PostgreSQL, with server-side validation and structured reporting.
- Rule-based matching with a 115-skill dictionary and a transparent, fully auditable scoring formula; no sensitive data sent to external services.
- Secure by design: safe upload validation, session authentication, per-user data isolation, rate limits, and email password reset.
- 254 backend tests (96% coverage), 57 frontend tests, and a Playwright end-to-end test, all run in GitHub Actions on every push.
- Deployed on Render with Neon PostgreSQL; Docker setup provided for self-hosting.
- 🔗 Live: https://careerforge-h362.onrender.com · Code: https://github.com/rakeshgangaraju10/AI-Intelligence-Resume
